CALENDARIO DE LAS 13 LUNAS - VERSION WEB / CELULAR
====================================================

USAR EN ESTE COMPUTADOR
-----------------------
Doble clic en "Servir Web.bat" y se abre en el navegador.

USAR EN EL CELULAR (misma red WiFi)
-----------------------------------
1. Abre "Servir Web.bat" en el computador.
2. En el celular, entra a la direccion que muestra la consola,
   reemplazando localhost por la IP del computador
   (ej: http://192.168.1.50:8137). Para ver tu IP:
   ejecuta "ipconfig" y busca Direccion IPv4.

COMPARTIR CON AMIGOS (por internet, gratis)
-------------------------------------------
Opcion A - Netlify Drop (la mas facil):
  1. Entra a https://app.netlify.com/drop
  2. Arrastra la carpeta "web" completa.
  3. Te da un enlace publico para compartir.

Opcion B - GitHub Pages:
  Sube el contenido de "web" a un repositorio y activa Pages.

APK ANDROID (version 1.9.1 rev. 20-oct-2026 incluida)
--------------------------------------
La carpeta "web" ya genera el APK nativo con Capacitor
(offline total, sin pasar por PWABuilder):
  - APK listo: dist-empaquetado/13-Lunas-offline-1.9.1.apk
    (recompilado 2026-10-20, versionName 1.9.1 / versionCode 4)
  - EXE Windows: dist-empaquetado/Calendario 13 Lunas 1.9.0.exe
    (portable, recompilado 2026-10-20 con fuentes src/ + parches a11y)
  - Para reconstruirlo: npm run movil:build
    (sincroniza web/ -> android/ y compila con Gradle).
  - Requiere Android SDK + JAVA_HOME configurado.
  - Alternativa sin compilar: publica "web" (Opcion A o B)
    y usa https://www.pwabuilder.com con la URL publica.

IPHONE / iOS
-----------
Opcion rapida (sin compilar, recomendada):
1. En Safari abre la direccion publica de la app
   (ej: https://calendario-13-lunas.pages.dev/).
2. Toca Compartir > "Anadir a pantalla de inicio".
3. Funciona sin internet (PWA offline con icono propio).

Opcion App Store (requiere Mac con Xcode + cuenta Apple Developer):
1. En el computador con el codigo fuente: npm run movil:ios:build
2. Copia la carpeta "ios" al Mac y abre ios/App/App.xcworkspace
3. En Xcode configura tu Team (Signing & Capabilities),
   Product > Archive y sube a TestFlight / App Store.
   Bundle ID: cl.penco.calendario13lunas - nombre: 13 Lunas.

NOTAS
-----
- Las notas y mareas se guardan en el navegador de cada dispositivo
  (no se sincronizan con la version de escritorio).
- En el celular usa "Agregar a pantalla de inicio" del navegador.
- En iPhone debe hacerse desde Safari (Chrome iOS no permite instalar PWA).
